Иерархия построена по схеме BR - штат - город. Пример формата path для поддерева GO — ST:GO - CT:GO:<город>. Базовая часть рекурсивного запроса выбирает начальный узел, а рекурсивная добавляет его детей при обходе вниз или родителя при обходе вверх. Запрос завершается, когда очередной шаг не добавляет строк.
